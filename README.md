# Adrian Hafezi — Portfolio

A responsive bilingual React portfolio with shared light/dark mode, English/Persian content, GSAP scroll reveals, and ten interactive local demo experiences.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev` and open the local URL shown by Vite.
5. For a production build, run `npm run build`.

## Included

- React + Vite application
- GSAP + ScrollTrigger motion with reduced-motion support
- English and Persian copy written in advance (no machine translation)
- Shared theme/language preferences stored in localStorage
- Ten interactive demos: storefront/cart, analytics dashboard, booking form, task manager, invoice builder, property finder/favorites, restaurant order, learning tracker, CRM, and creative portfolio filter
- Demo data and user changes stored locally in the browser
- Responsive layouts, custom favicon, scroll progress/back-to-top control

## Notes

The demos are front-end prototypes. They intentionally use localStorage and sample data instead of a remote database or payment service. Images and Google Fonts load from external URLs, so an internet connection is needed for those assets. Replace the sample email/contact details if you add an email link later.
